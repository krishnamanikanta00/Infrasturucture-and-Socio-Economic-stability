# Affordable Living, Better Life 🏠

> A Design Thinking Project on Infrastructure & Socio-Economic Stability

---

## About the Project

This project explores how **housing affordability and transportation challenges** affect students and young professionals in urban India. Using a human-centered design approach, it identifies key pain points and proposes practical solutions to improve quality of life.

The website is built as a university-style design thinking portfolio — covering the full design process from problem discovery to solution proposals.

## Key Findings

- **87%** of surveyed students face rent affordability pressure
- **81%** report long daily commutes as a major burden
- Average commute time: **3.2 hours/day**
- Rent consumes up to **45% of monthly income**

---

## Proposed Solutions

1. Smart Housing Recommendation System
2. Commute-Time Calculator
3. Verified Housing Listings
4. Roommate Matching Platform
5. Affordable Shared Living Communities
6. Integrated Housing + Transportation Services
